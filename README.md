# FareTicketHunter

Personal flight price monitor for Turkish Airlines. Watches selected routes, alerts via Telegram when prices drop.

→ See [DESIGN.md](./DESIGN.md) for full architecture, data model, and roadmap.

## Quick start (coming soon)

```bash
cp .env.example .env
# fill in TA_API_KEY, TELEGRAM_BOT_TOKEN, etc.
docker compose up
```
